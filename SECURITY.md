# 🔐 Security Policy

## Reporting a security issue

If you discover a security-related problem in this repository, please avoid posting sensitive details, credentials or private information publicly.

For ordinary gameplay bugs, crashes and feature problems, use GitHub Issues and the provided Bug Report template.

For a security concern that should not be described publicly, contact:

**kodaniq@outlook.com**

Please include:

- which file or game is affected
- a clear description of the problem
- steps to reproduce it, when applicable
- the potential impact
- any suggested fix, if you have one

Do **not** include real passwords, API keys, access tokens or other secrets in your report.

## Supported versions

This project currently follows the latest version available on the repository's `main` branch. Older copies are not maintained as separate supported versions.

## Scope

This is a collection of local standalone Python games. Save data is stored locally in JSON files. The repository does not intentionally require accounts, cloud authentication or secret credentials to play the games.
