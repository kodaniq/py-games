# Code of Conduct

## Our standard

This project welcomes people who want to play, learn from or improve the games. Discussions, issues, reviews and contributions should stay constructive and respectful.

Examples of positive participation include:

- giving useful and specific feedback
- focusing criticism on code or behavior rather than people
- helping others reproduce and understand bugs
- respecting different experience levels
- accepting reasonable feedback on contributions

Unacceptable behavior includes harassment, personal attacks, threats, discriminatory comments, deliberate disruption, spam and publishing another person's private information without permission.

## Scope

This Code of Conduct applies to participation in this repository, including Issues, Pull Requests and other project discussions.

## Reporting

If behavior in this project needs moderator attention, contact **kodaniq@outlook.com**. Reports should include enough context to understand what happened without including unrelated private information.

Project maintainers may edit, remove or reject contributions and comments that violate these expectations, and may restrict participation when necessary to keep the project usable and welcoming.
